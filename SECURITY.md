# Security

Mora handles household financial figures and, for screenshot import, the user's own AI API key. Please report security problems privately.

## Reporting a vulnerability

Use GitHub's private reporting: open the repository's **Security** tab and choose **Report a vulnerability**. Please do not open a public issue, and do not include real financial data or real API keys in a report.

You should hear back within a week.

## What counts

For example:

- A way for financial data or an API key to leave the browser (or the skill's local files) other than the calls the user set up to their own AI provider.
- A way for page content, a screenshot or a saved review file to run script in the web app or in a generated HTML report.
- An API key ending up in a build, a commit, a log or a saved review.

## Supported versions

Only the latest release and the `main` branch get fixes.

# 安全问题

Mora 会处理家庭财务数据，使用截图导入时还会用到你自己的 AI API Key。发现安全问题，请私下报告。

在仓库的 **Security** 标签页选择 **Report a vulnerability** 提交。请不要公开提 issue，报告里也不要附真实的财务数据或 API Key。一般一周内会回复。只有最新版本和 `main` 分支会修复。
